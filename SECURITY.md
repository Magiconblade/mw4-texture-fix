# Security Policy

## Reporting a Vulnerability

For any abuse reports or security concerns, please open an issue in this repository.

We take all reports seriously and will respond within 48 hours.

## Scope

This tool modifies the Windows hosts file and creates a local cache mirror. It does not:
- Inject DLLs into game processes
- Modify game memory
- Access network resources beyond the game's own CDN
- Collect telemetry
